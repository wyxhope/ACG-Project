# ACG-Project: Rigid, Fluid and Cloth Simulation


## How to use

This project proposes a system for simulating rigid, fluid and cloth. 

The file `main.py` defines the basic method of producing a video demo of a chain reaction. If you want to run it youself, use the following bash: \

`"C:\Program Files\Blender Foundation\Blender 5.0\blender.exe" --background --python main.py`

Also this project contains a gui to observe the interaction between rigid body and cloth in realtime, you are able to drag the rigid ball and see the simulation. \
`python interactive.py`
